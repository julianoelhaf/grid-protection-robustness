# DPSP Global 2026

Planned independent benchmark version. The classification target has eleven
classes and the localization target is position. The grouped-fold aggregation
uses population standard deviation.

Release requires binding the 290-fit PROTECT-90 rerun to its exact source, data,
folds, and environment, plus author approval of contributor credit and
redistribution. The historical patched execution remains unidentified. Physical
bus assignments for the DPSP relay groups remain unverified. This repository
currently ships EUSIPCO.
