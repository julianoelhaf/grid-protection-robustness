# Grid Protection Robustness

The EUSIPCO v2.0.0 benchmark evaluates random-forest fault detection and line
identification under sparse measurements. It covers 9,022 PROTECT-90 episodes
across four fault types, 260 cases, and 1,300 held-out fold fits.
